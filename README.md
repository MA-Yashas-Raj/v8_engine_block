# V8 Engine Block – CAD Modeling Project

![V8 Engine Block](Images/engine-block.png)

## Overview

This project is a **3D CAD model of a V8 engine block**, created using **Autodesk Fusion 360**.

The project focuses on developing the engine block geometry using parametric modeling techniques, with emphasis on accurate geometry, repeated features, symmetry, and mechanical design principles.

---

## Engine Block

The model includes:

- V8 cylinder arrangement
- Cylinder bores
- Cylinder head mounting surface
- Head bolt mounting locations
- Engine block exterior geometry
- Fillets and edge detailing
- Internal cylinder openings
- Parametric CAD features

---

## Design Process

The engine block was developed using:

1. Initial sketches and reference geometry
2. Extrusion and cutting operations
3. Cylinder bore creation
4. Pattern features for repeated geometry
5. Symmetry and dimensional constraints
6. Fillets and edge finishing
7. Iterative refinement of the final geometry

The model was created as a **parametric and editable CAD model** rather than a static 3D shape.
